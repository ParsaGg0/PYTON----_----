# 🎮 Tic-Tac-Toe | Python

A simple **console-based Tic-Tac-Toe game** built with Python as part of my journey of learning by building.

These projects  focuses on practicing core Python concepts while creating a playable game from scratch. 

## 🚀 About the Project

This project is a two-mode Tic-Tac-Toe game:

- 👤 **1 vs 1** — two players can play against each other.
- 🤖 **1 vs Computer** — the computer chooses an available position randomly.

The game runs directly in the terminal/console and includes basic game-state validation for moves, wins, and draws.

## 🧠 What I Practiced

Through this project, I worked with:

- Python functions
- Lists and data structures
- `if / elif / else` conditions
- `while` and `for` loops
- User input and string parsing
- The `random` module
- Basic game-state management
- Win and draw detection
- Console-based UI
- Structuring logic into reusable functions

## ⚙️ How It Works

The board is represented using three lists, while separate functions handle:

- Player moves
- Empty-position validation
- Win detection
- Game completion
- Board rendering

The computer opponent currently uses **random valid moves** rather than an AI strategy.

This project is not about building a complex game engine.
